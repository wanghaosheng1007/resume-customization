# Acme Corp — Senior Backend Engineer (demo JD)

**Company:** Acme Corp  
**Location:** Remote (US)  
**Team:** Platform Infrastructure

## About the role

We are looking for a Senior Backend Engineer to design and operate high-throughput data ingestion and APIs serving internal and external customers.

## Responsibilities

- Design and implement scalable backend services in Python or Go
- Own event-driven pipelines (Kafka or similar) and improve reliability
- Reduce latency and operational burden through observability and SLOs
- Mentor engineers and lead technical design reviews
- Collaborate with SRE on incident response and capacity planning

## Requirements (must have)

- 5+ years backend development
- Strong Python **or** Go in production
- Experience with message queues / streaming (Kafka, Kinesis, etc.)
- SQL databases (PostgreSQL preferred) and query performance tuning
- Cloud experience (AWS or GCP)
- Distributed systems and API design

## Nice to have

- Kubernetes in production
- Terraform / IaC
- Payment or fintech domain
- OpenTelemetry or distributed tracing

## Keywords

Python, Go, Kafka, PostgreSQL, AWS, microservices, FastAPI, system design, mentoring, on-call, SLOs, observability
